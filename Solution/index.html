sweet.tv — TV Programme Recommender

LLM4Rec final exam (AVITO cohort): join the view log to the labelled broadcast schedule, fit four course methods on weeks 11–20, compare them by MAP@5 on weeks 21–30, then refit on weeks 11–30 and predict five programmes per test user for weeks 31–42.

Every method shares one protocol: the same candidate pool (programmes that air in the target window), the same repeat rule (already-watched programmes may be recommended), the same fallback (popularity) and the same evaluation cohort.
